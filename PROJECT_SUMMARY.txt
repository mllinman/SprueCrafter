• Automatic format detection
• Mesh validation and repair
• Watertight mesh verification

SCALING:
• 1/35 scale (primary)
• 1/48, 1/72, 1/144 (standard scales)
• Custom scale support
• Unit conversion (mm, cm, in, m)
• Real-world dimension calculation

PART SEPARATION:
• Connected component analysis
• Automatic geometry splitting
• 6 smart categories:
  - Body (hull, chassis, fuselage)
  - Turret (gun mounts)
  - Weapons (guns, cannons, missiles)
  - Wheels (tracks, suspension)
  - Details (antennas, hatches, vents)
  - Accessories (figures, crew, bases)

SPRUE GENERATION:
• Professional-quality layouts
• Optimized bin packing algorithm
• 2mm main runners
• 1mm connection gates
• 5mm minimum spacing
• 2mm elevation above build plate
• Automatic orientation for minimal supports
• Multi-sprue set generation

PHOTOGRAMMETRY:
• Multi-image processing
• Feature detection (ORB)
• Point cloud generation
• Mesh reconstruction
• Relief model creation
• Depth estimation

• Creality Halot One (127×80×160mm)
• Custom dimensions support

QUICK START:
1. Run setup:         ./setup.sh (or setup.bat)
2. Start app:         npm start
3. Import model:      Drag-and-drop 3D file
4. Scale to 1/35:     Select scale preset
5. Generate sprue:    Choose printer profile
6. Export:            Save STL for printing
7. Print:             Load in slicer and print!

TYPICAL WORKFLOW:
1. Import 3D model (any format)
2. Convert to STL if needed
3. Scale to 1/35th or custom scale
4. Separate into categorized parts
5. Generate professional sprue layout
6. Review in 3D viewer
7. Export for resin printer
8. Print and build model!
