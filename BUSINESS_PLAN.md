# SprueCrafter Business Plan

**Version:** 1.0  
**Date:** January 2026  
**Company:** SprueCrafter  
**Product:** Professional 3D Model to Sprue Conversion Tool for Resin Printing

---

## Executive Summary

SprueCrafter is a professional desktop and web-based application that converts 3D models into 1/35th scale model sprues optimized for resin 3D printing. The application targets the growing intersection of two rapidly expanding markets: 3D printing enthusiasts and scale modeling hobbyists.

### Key Highlights

- **Target Market:** Scale modelers, miniature enthusiasts, tabletop gamers, and 3D printing hobbyists
- **Market Size:** $13.8B global 3D printing market (2023) growing at 23.3% CAGR, plus $2.1B scale modeling market
- **Business Model:** Freemium SaaS with optional Pro subscription ($10/month)
- **Unique Value Proposition:** Industry-quality sprue generation rivaling Meng and Takom, with modern automation and AI-powered features
- **Distribution:** Web-based SaaS and downloadable desktop application (Windows, Mac, Linux)
- **Revenue Goal:** $100K ARR by Year 1, $500K ARR by Year 3

## 2. Market Analysis

### 2.1 Industry Overview

#### 3D Printing Market
- **Global Market Size:** $13.8 billion (2023)
- **Projected Growth:** $63.5 billion by 2032
- **CAGR:** 23.3% (2024-2032)
- **Resin Printing Segment:** Fastest growing segment at 28% CAGR
- **Consumer Adoption:** 45% year-over-year growth in consumer 3D printers

#### Scale Modeling Market
- **Global Market Size:** $2.1 billion (2023)
- **Projected Growth:** $2.9 billion by 2030
- **CAGR:** 4.5% (2023-2030)
- **Digital Integration:** Growing trend toward hybrid physical-digital workflows

#### Key Market Trends

1. **Democratization of 3D Printing**
   - Decreasing printer costs (quality resin printers now under $300)
   - Improved ease of use
   - Growing hobbyist community

2. **Content Creation Boom**
   - Rise of STL marketplaces (MyMiniFactory, Cults3D, Thingiverse)
   - Creator economy growing at 20% annually
   - Demand for model preparation tools

3. **Customization Demand**
   - Personalized miniatures and models
   - Custom scale conversion
   - Unique sprue layouts

4. **Quality Expectations**
   - Professional-grade results expected at consumer level
   - Industry-standard quality now accessible to hobbyists
   - Reduced tolerance for printing failures

### 2.2 Target Market

#### Primary Target Segments

**1. Scale Model Enthusiasts (40% of market)**
- Age: 25-65
- Income: $40K-$100K+
- Characteristics: Detail-oriented, precision-focused, quality-conscious
- Pain Points: Limited access to specific models, high retail costs, customization constraints
- Size: ~500K active enthusiasts globally

**2. Tabletop Gaming Community (30% of market)**
- Age: 18-45
- Income: $30K-$80K
- Characteristics: Creative, cost-conscious, community-driven
- Pain Points: Expensive miniatures, limited customization, slow retail availability
- Size: ~2M active 3D printing gamers globally

**3. 3D Printing Hobbyists (20% of market)**
- Age: 20-50
- Income: $35K-$90K
- Characteristics: Tech-savvy, experimental, efficiency-focused
- Pain Points: Complex workflows, print failures, lack of automation
- Size: ~5M resin printer owners globally

**4. Professional Model Makers (10% of market)**
- Age: 25-60
- Income: $50K-$150K+
- Characteristics: Quality-focused, time-sensitive, professional requirements
- Pain Points: Manual processes, workflow inefficiencies, quality consistency
- Size: ~50K professionals globally

#### Secondary Target Segments

- Educational institutions (STEM programs)
- Small model manufacturing businesses
- 3D scanning services
- Prop makers and costume designers
- Museum reproduction departments

### 2.3 Competitive Analysis

#### Direct Competitors

**1. Chitubox Pro**
- **Strengths:** Established brand, large user base, slicer integration
- **Weaknesses:** Limited sprue generation, complex interface, requires subscription for advanced features
- **Price:** Free basic, $169/year Pro
- **Market Position:** Industry leader in resin printing software

**2. Lychee Slicer**
- **Strengths:** Modern UI, excellent support generation, active development
- **Weaknesses:** No sprue-specific features, focused on slicing rather than preparation
- **Price:** Free basic, $60/year Pro
- **Market Position:** Growing challenger to Chitubox

**3. Meshmixer (Autodesk)**
- **Strengths:** Powerful mesh editing, free, established tool
- **Weaknesses:** Complex learning curve, no sprue-specific tools, discontinued development
- **Price:** Free
- **Market Position:** Legacy tool with declining relevance

**4. Manual Sprue Creation (CAD Software)**
- **Strengths:** Complete control, professional results possible
- **Weaknesses:** Time-consuming, steep learning curve, expensive software (Blender free, but difficult; ZBrush $40/month)
- **Price:** Variable ($0-$1000+)
- **Market Position:** High-end professional solution

#### SprueCrafter Competitive Advantages

1. **Specialized Focus:** Only tool dedicated to sprue generation for scale models
2. **AI-Powered Automation:** Intelligent part categorization and layout optimization
3. **Accessibility:** Free core features with gentle learning curve
4. **Modern Technology Stack:** Web-based and desktop options, continuous updates
5. **Industry Quality:** Results rival Meng, Takom, and other premium manufacturers
6. **Comprehensive Workflow:** Import to export in one application
7. **Price Point:** Free for core features, affordable Pro option ($10/month vs competitors' $60-$169/year)
8. **Format Support:** Supports 10+ file formats out of the box
9. **Active Development:** Regular feature updates and community engagement

#### Competitive Positioning

**Market Position:** Premium Quality at Accessible Pricing  
**Differentiation:** Specialized sprue generation + AI automation + Professional results  
**Strategy:** Freemium model to capture market share, Pro features for revenue

## 3. Product & Services

### 3.1 Core Product: SprueCrafter Application

#### Free Tier Features
- Universal 3D file conversion (STL, OBJ, FBX, 3DS, PLY, GLTF, GLB, DAE)
- Intelligent scale conversion (1/35, 1/48, 1/72, 1/144, custom)
- Smart part separation
- AI-powered part categorization
- Professional sprue generation with multiple connector types
- Model transformation tools
- Support generation (automatic and manual)
- Photo-to-3D conversion (photogrammetry)
- Island detection
- One-click mesh repair
- Mesh quality analysis
- Advanced hollowing with material savings calculator
- Batch processing
- 3D viewer and inspection tools
- Community support

#### Pro Tier Features ($10/month)
- Priority email support (24-48 hour response time)
- Advanced batch processing (unlimited files)
- API access for automation and integration
- Early access to new features (beta testing)
- Extended file format support
- Cloud storage for projects (5GB)
- Custom printer profiles (unlimited)
- Advanced analytics and reporting
- Commercial use license
- Support SprueCrafter development

### 3.2 Distribution Channels

#### Web Application (SaaS)
- Browser-based access (no installation required)
- Cross-platform compatibility
- Automatic updates
- Cloud-based processing
- Deployment: Railway, AWS, or similar platforms

#### Desktop Application
- Windows, macOS, Linux
- Offline functionality
- Full feature parity with web version
- Local file processing for privacy
- Distribution: Direct download, GitHub releases

### 3.3 Technical Architecture

- **Frontend:** Electron + HTML/CSS/JavaScript + Three.js
- **Backend:** Python Flask API
- **3D Processing:** Trimesh, NumPy, SciPy, PyMeshLab, Open3D
- **AI/ML:** OpenCV for photogrammetry and image processing
- **Database:** SQLite (local), PostgreSQL (SaaS)
- **Payment Processing:** Stripe for subscription management
- **Infrastructure:** Railway (primary), Docker containers

**Risk:** Low conversion rates (free to Pro)
